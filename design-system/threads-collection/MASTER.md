## 1. 產品原則

1. **內容優先**：卡片牆就是首頁，畫面的主角是使用者收藏的內容，介面元素退到後面。
2. **收藏要快**：從 Threads 分享到存好，最快一次點擊（直接按「完成」）。標籤可以之後補。
3. **整理不強迫**：沒標籤的放「未分類」，不阻擋收藏。
4. **離線也看得到**：卡片的文字與小縮圖存在手機；原始大圖、影片需要時才抓。
5. **不誤導**：不顯示會變動的數字（讚數、留言數）；原貼文刪除要明確標示。

## 4. 間距、圓角、陰影

- **間距（4/8 系統）**：`xs 4`、`sm 8`、`md 12`、`lg 16`、`xl 24`、`2xl 32`、`3xl 48`。
- 畫面左右邊距 `20`；瀑布流欄距 `16`、上下卡片間距 `20`；區塊之間 `24`。卡片沒有內距（沒有框）。
- **圓角（雜誌的方角）**：`xs 3`（卡片圖片、文字卡）、`sm 4`（標籤、搜尋列）、`md 8`（按鈕、輸入框、提示）、`lg 12`、`sheet 16`（面板上緣）、`full`（FAB、開關）。
- **陰影（扁平風格，只用兩層）**：
  - `level0`：無陰影，只有 1px `border`（卡片預設）。
  - `level1`：FAB、按住中的卡片 — RN `elevation: 3`，iOS `shadowOpacity 0.12, radius 8, offsetY 2`。
  - `level2`：面板 — `elevation: 8`，iOS `shadowOpacity 0.18, radius 16`。
- 反模式：不用複雜陰影、3D、玻璃擬態、漸層裝飾（資料庫 AVOID 清單）。

## 5. 圖示

- 圖示庫：`@expo/vector-icons` 的 **Ionicons**（全 App 一套）。
- 一般動作用 outline；「已選取、已啟用」狀態用 filled（同一層級不混用）。

## 6. 觸控與互動

- **點擊區域**：Android ≥ **48×48dp**、iOS ≥ 44×44pt（`TOUCH = Platform.select({ android: 48, ios: 44 })`）；圖示小於這個大小時擴大點擊範圍。點擊目標之間至少 8dp。
- **按壓回饋**：100ms 內出現；卡片與按鈕 `scale 0.97`＋透明度，不得改變排版尺寸（不推擠旁邊的卡片）。
- **長按卡片**：開啟卡片選單（設為精選 / 編輯標籤 / 下載 / 選取多篇 / 刪除）。長按是捷徑，**每個長按動作在內容頁都要有看得到的按鈕**（`gesture-alternative`）；「選取多篇」的看得到的入口是牆頂部列的 ✓ 圓圈按鈕。
- **觸覺回饋**：只在三種時刻 — 收藏成功、出錯、長按開啟選單。
- **刪除**：不跳確認視窗，改成底部提示「已刪除 · 復原」5 秒（`undo-support`）。刪除標籤（會影響多張卡片）才跳確認。
- 不在主要內容區做水平滑動手勢（避免和系統返回手勢衝突）；例外是媒體輪播（內容頁、串流，要有頁碼與指示點）和翻翻的卡片（離螢幕邊緣 20dp，避開系統返回手勢；每個滑動都有同功能的按鈕，可復原）。

## 7. 動態

沿用 `src/ui/motion.js` 的彈簧（Apple 的 response / damping 參數）：

| Token | 參數 | 用途 |
| --- | --- | --- |
| `press` | response 0.25、damping 1 | 按壓縮放 |
| `standard` | response 0.35、damping 1 | 卡片出現、狀態切換、標籤選取 |
| `sheet` | response 0.35、damping 0.9 | 面板滑入（離開時用 0.25，比進入快約 2/3） |
| `stagger` | 每張 40ms，最多前 8 張 | 只在第一次載入卡片牆時 |

- 只用 transform / opacity 做動畫，不動寬高（瀑布流切換精選時用淡入淡出取代尺寸動畫）。
- 開啟「減少動態效果」：取消縮放、錯開與滑入，只保留 150ms 淡入淡出。
- 所有動畫都可以被打斷，動畫中仍可操作。

## 8. 畫面架構與導覽

| 畫面 | 類型 | 說明 |
| --- | --- | --- |
| 收藏牆（首頁） | 分頁「收藏」（預設） | 頂部列（＋、搜尋、設定）＋一列可橫向捲動的標籤＋「所有標籤 ›」＋瀑布流 |
| 所有標籤 / 標籤頁 | 「收藏」分頁內推入 | 每個大標籤一張封面（兩欄）＋「整理未分類」；標籤頁＝該標籤的牆＋小標籤列＋「用串流看 ›」 |
| 翻翻 | 分頁（左） | 一次一張卡：右滑精選、左滑下一張、上滑加標籤，下方按鈕同功能、可復原；選「未分類」＝整理模式（右滑套用建議） |
| 串流 | 分頁（右） | 單欄、完整內文、媒體輪播、影片點了才播（全 App 同時只播一支）；最新收藏 / 隨機 |
| 貼文內容 | 推入新頁 | 媒體、完整內文、標籤、動作 |
| 作者頁 | 「收藏」分頁內推入（2026-11-07） | 返回箭頭＋`@handle`（`title` 字級）＋選取、搜尋；「N 篇 · 最常用標籤：追星、生活」＋「用串流看 ›」；牆＝這位作者的貼文。入口：內容頁的署名列「文 ／ @handle ›」與頂部的 @handle、串流每篇的署名、翻翻卡片上的 @handle（底線）。卡片牆上的 @handle **不做**連結：兩欄卡片上它只有 16px 高，整張卡已經是開啟內容頁的點擊目標，再塞一個 48dp 目標會互相搶 |
| 批次選取 | 收藏牆、標籤頁、作者頁上的模式（2026-11-07） | 見 §9「批次選取」 |
| 收藏面板 | 底部面板 | 分享進來或貼網址後出現；選標籤、同時下載 |
| 卡片選單 | 底部面板 | 長按卡片 |
| 標籤管理 | 推入新頁（第二階段） | 改名、合併、刪除、換顏色 |
| 設定 / 帳號 | 推入新頁 | 登入 Threads、備份（第三階段）、關於 |

- 底部分頁列（2026-11-02 使用者核准）：翻翻｜收藏｜串流，預設「收藏」。細線上緣、圖示＋文字，目前分頁＝墨色＋上緣 2px 粗線＋實心圖示，高 ≥ 56 並避開手勢列。返回鍵：先關最上層（收藏面板、批次面板〔N 篇的標籤 / 刪除確認〕、貼網址、設定、選單、內容頁），再結束批次選取，在翻翻 / 串流時回到收藏，收藏內依序關作者頁、標籤頁、所有標籤，最後才離開 App（規則在 `navModel.js`，有測試）。
- 作者頁記得從哪裡來（`navModel.openAuthor`）：從串流 / 翻翻點進來，返回回到那個分頁；從內容頁點進來，返回重新打開那篇內容頁（貼文已刪除就不開）。在作者頁的內容頁再點同一位作者，只關掉內容頁。網頁版測試用 `window.__pressBack()` 模擬返回鍵（`hardwareBack.web.js`）。
- 批次選取只屬於開始它的那面牆（`navModel.wallKey`）：換到別的頁、返回、離開收藏分頁都會結束；捲動、篩選不會（篩選或搜尋藏起來的卡片會從選取裡拿掉，動作只作用在看得到的卡片）。
- 返回要保留捲動位置、篩選與搜尋內容（`state-preservation`）。
- 深層連結：`threadsdownloader://post/<code>` 開啟內容頁（實作時加入）。
- 正式實作改用 Expo Router（專案規範），每個推入頁是一個路由。目前分頁是 App.js 裡的自製分頁列：expo-share-intent 在 Expo Router 下以深層連結進來，需要 `+native-intent` 轉址，那只在原生端執行、網頁測試驗證不到，等可以實機測試時再搬。

## 9. 元件規格（摘要，細節見各頁面檔）

### PostCard（收藏卡，雜誌版面）
- 變體：`media`（圖片 / 影片 / 多張）、`quote`（純文字）、`featured`（整排精選，任一類型都可）。
- 狀態：`loading`（骨架＋「讀取中」）、`ready`、`failed`（細框盒＋「讀取失敗 / 需要登入」＋重試）、`sourceDeleted`、`downloaded`。
- 結構：圖片（無框、圖上不放任何角標，高寬比限制在 0.75–1.6）→ 欄目標（標籤色小方塊＋標籤名，「+N」）→ 文楷內文最多 3 行 → 資訊列（@作者、▶ 影片 / N 張、已刪除、已下載，**都用文字＋小圖示**）→ 卡片下方一條細線。
- 純文字卡：標籤色文字卡（見 §2.2）＋大「「」，之後同樣接欄目標與資訊列。
- 精選：整排；欄目標前多一個 `accent` 色的「精選」，標籤名顯示完整「大標籤 › 小標籤」，內文用 `cardFeatured`。
- 無障礙：整張卡片一個可點元素，標籤念出「精選、作者、類型、內文前 30 字、標籤、已刪除、已下載」。

### TagChip
- 變體：`choice`（篩選列、收藏面板，可選）、`display`（內容頁，不可點）。樣式見 §2.2。
- 高度：可點的 ≥ 36 視覺高度，點擊範圍補到 48；`display` 24。
- 已選狀態必有 ✓ 圖示＋`accessibilityState.checked`。

### TagFilterBar
- 第一列：「全部」＋大標籤，**換行顯示，最多兩行，其餘收進「+N」**（`chip-collection-reflow`），點「+N」展開全部。
- 選了大標籤後，下方出現它的小標籤列（同樣規則）；選大標籤＝包含所有小標籤的貼文。

### 報頭

### 批次選取（`ui/Selection.js`，2026-11-07）
- **入口**：牆的頂部列（收藏、標籤頁、作者頁同一個位置）一個 ✓ 圓圈圖示「選取多篇」，進入時什麼都沒選；長按卡片選單的「選取多篇」是捷徑，進入時那張已勾。不用「長按後拖曳」：瀑布流裡拖曳會和捲動搶手勢。
- **頂部**：報頭那列換成 `display`「已選 N 篇」＋「全選」（全部勾了變「全不選」）＋「取消」，高度不變，捲動位置不跳；上方小字換成「點卡片勾選，再選下方的動作」。
- **卡片**：整張卡是一個 checkbox（`accessibilityState.checked`），點一下勾 / 取消，長按也一樣。已勾＝卡片外圍 2px `foreground` 框（畫在欄距裡，不推擠瀑布流）＋左上角實心圓 `foreground` 底、`background` 的 ✓ 和外圈；沒勾＝`badge` 半透明圓＋`onBadge` 外圈。形狀不同，不只靠顏色。圓放在照片左上角（底片的「N 張」在右上、▶ 影片與日期在下面）；這是 §11「照片上不放角標」唯一的例外，只在選取時出現。讀取中 / 讀取失敗的卡片不能選，顯示成 40% 透明。
- **動作列**：分頁列正上方，`card` 底＋上緣細線，四個等寬按鈕（圖示在上、`label` 字在下，高 64）：加標籤、精選 / 取消精選（全部已精選時）、下載、刪除（`danger`）。還沒勾時全部停用。牆的清單在動作列上方結束，最後一張卡不會被蓋住；下載提示條在選取時往上移一個動作列高。
- **加標籤**（`BatchTagSheet`）：每個標籤是三態 checkbox：全部有＝墨色填滿＋✓；部分有＝`foreground` 虛線框＋「—」＋「追星 2/3」（`checked: 'mixed'`）；都沒有＝一般。點一下循環（`batch.cycleState`），部分有的再點一輪回到「不變」。底部寫出這次會「加上：… · 移除：…」，「套用到 N 篇」只改使用者點過的標籤（`batch.diffStates`）。可以新增標籤（新標籤直接是「全部有」）。套用後保留選取。
- **精選**：一次設定全部；完成後保留選取，按鈕變「取消精選」。
- **下載**：把可下載的依序放進下載佇列（輪播仍會問要哪幾張），純文字 / 原文已刪除的略過並在提示說「N 篇沒有可下載的媒體」；結束選取。
- **刪除**：唯一要確認的批次動作（「刪除 N 篇收藏？」＋「刪除 N 篇」外框紅字按鈕）；刪除後結束選取，提示「已刪除 N 篇收藏 · 復原」，復原把全部放回原位（`store.removeMany` / `undoRemove`）。

## 10. 無障礙重點

- 文字對比 ≥ 4.5:1（兩種模式分開驗證）；有意義的圖示與控制邊界 ≥ 3:1。
- 顏色不是唯一線索：已選標籤有 ✓、錯誤有圖示＋文字、影片有 ▶ 角標。
- 螢幕閱讀器順序＝視覺順序；瀑布流依「放進牆的順序」朗讀，不依欄位。
- 系統字體放大到最大時不重疊、不截掉按鈕。
- 提示訊息（Toast）不搶焦點，以 polite 方式朗讀。

## 11. 反模式（禁止）

- ❌ 用 emoji 當圖示
- ❌ 在照片上疊角標或文字（雜誌版面把資訊放在圖片下方）
- ❌ 除了 `accent` 以外再加一個彩色強調色
- ❌ 只靠顏色表示選取或狀態
- ❌ 把標籤硬擠成一行並截掉
- ❌ 長按是唯一入口的功能
- ❌ 會推擠排版的按壓效果、動畫寬高
- ❌ 複雜陰影、3D、裝飾漸層
- ❌ 顯示會過期的數字（讚數）
- ❌ 卡片牆用 ScrollView + map 渲染大量卡片（要用虛擬化清單）

## 16. 主題（雜誌 / 底片）

### 16.1 架構

- 主題清單在 `app/src/collection/themes.js`（純資料，沒有 RN import）：每個主題有 `name`、淺色與深色兩組 `colors`（全部 30 個 token，見 `COLOR_TOKENS`）、`knobs`（版面開關與圓角）。`test/themes.test.mjs` 檢查每個主題、每個模式都定義齊全。
- 使用者在 **設定 › 主題**（雜誌 | 底片 分段按鈕）切換，立即生效；選擇存在 SQLite `meta` 表的 `theme`（`store.js`，和 `quick_save` 同一套），預設 `editorial`，讀到不認得的值也回到預設。
- `CollectionProvider` 把選擇放進 `ThemeProvider`（`tokens.js`），所以 App 裡所有畫面都拿得到。主題在開啟資料庫後最先讀，早於預設標籤與舊紀錄搬移。

### 16.2 畫面怎麼用（新畫面照這個寫）

```js
const t = useCollectionTheme();
// 顏色：t.background、t.card、t.foreground、t.mutedForeground、t.outline、t.accent…（和以前一樣）
// t.scheme 'light' | 'dark'；t.theme 'editorial' | 'film'；t.themeName '雜誌' | '底片'
// t.font.display / title / card / quote / kicker / imprint …   ← 不要再 import { font }
// t.radius.xs / sm / md / lg / sheet / full                    ← 不要再 import { radius }
// 版面開關：t.printFrame、t.rule ('line' | 'sprocket')、t.marker ('square' | 'bar')、
//          t.textCard ('tint' | 'lined')、t.kickerTone ('tag' | 'muted')
// 標籤色：t.tag(hue) → { mark, text, paper, onPaper, onPaperMuted, paperRule }
```

元件（`app/src/collection/ui/theme/`，`import { … } from './theme'`）：

| 元件 | 用途 | 雜誌 | 底片 |

**規則**
1. **文字顏色和它底下的面一起選。** 文字只能用和底色同一組的 token：頁面 / 面板上用 `foreground`、`mutedForeground`、`accent`、`danger`；標籤卡紙上用 `t.tag(hue).onPaper` / `.onPaperMuted`（紙用 `.paper`）；相片白邊上用 `onEdge` / `onEdgeMuted`；照片上的小標示用 `badge` + `onBadge`；墨色填滿（已選標籤、提示、按下的列）上用 `background`（或面板上用 `card`）。**不要**把某主題的底色配另一組的字色，也不要自己算色票（之前預覽就是深色標籤底配深色字才看不見）。
2. 舊的 `tagColors()`、`tagTint()`、`font`、`radius` 仍可 import（等於雜誌的值），只為了還沒改的檔案能編譯；新畫面一律用 `t.*`。
3. 照片上只放三種東西：日期壓印（只在 `t.printFrame`）、▶ 影片、N 張。不要序號（No.11、ROLL、FRAME）、不要英文分頁名。
4. 影片播放時把日期壓印藏起來（`imprint={false}`），免得蓋住原生控制列。
5. 改任何色碼後跑 `contrast_check_themes.py`。

| `card` | 14 / 22 文楷（媒體卡 2 行） | 15 / 23（3 行） |
| `quote` | 16 / 26 文楷（行高 = 紙上橫線間距） | 18 / 28 |
| `kicker` | 12 / 16 / 500，字距 1 | 12 / 16 / 600，字距 1.5 |
| `imprint` | 12 / 14 ImprintMono（兩個主題都有） | 同左 |

- **標題不用系統 `serif`**：AOSP 的 `fonts.xml` 只把 `NotoSerifCJK-Regular.ttc`（400）設成 zh-Hant 的 `fallbackFor="serif"`，沒有粗體，而且各廠牌 ROM 會換掉字型設定，不保證有宋體。所以標題改用已經打包的文楷 Bold，不另外打包好幾 MB 的中文明體。
- **日期字**：IBM Plex Mono Medium 的數字子集（`0-9 ' 空白 . , : / - ·`，3.7 KB），因為 Plex 有保留字型名稱，子集改名為 `ImprintMono`（見 `app/assets/fonts/README.md`）。Android 用 expo-font 設定外掛註冊成 XML 字族 `ImprintMono`；網頁版由 `fonts.web.js` 載入。
- 網頁版的文楷 Bold 另外註冊成 `WenKaiBold` 字族（不再加 `fontWeight`，避免瀏覽器再加粗一次）。

### 16.5 底片元件樣式

- **卡片牆**：照片是 `<Print>`；卡片之間不畫細線；欄目標＝直條＋`mutedForeground` 名稱；內文 2 行；資訊列只在有「已刪除 / 已下載」時出現（▶ 影片、N 張在照片上，作者在文字卡背面）。純文字貼文是 `<PhotoBack>`。
- **標籤膠囊**：方角、直條記號；已選＝墨色填滿＋✓。
- **面板**：方角上緣；標題文楷 Bold。按鈕方角。
- **內容頁**：媒體輪播放進相片框（左右各留 14 的頁面），右下日期壓印（影片播放時隱藏）；純文字貼文是大一號的相片背面。
- **回顧卡**：上緣的墨線換成細齒孔條。
- 卡片牆的報頭：`t.font.display`，下面放 `<MastheadRule />`，上方小字在底片只寫「N 篇」（雜誌「THREADS 收藏誌 · N 篇」）。
- **底部分頁列**：兩種模式都是深色膠卷條（`tabBar`），文字與圖示用 `onTabBar`（目前分頁，實心圖示＋粗體）/ `onTabBarMuted`，目前分頁圖示上方一個 `stamp` 橘色小條；只有中文分頁名。
- **所有標籤**：封面是一張相片（`<Print>`，有日期壓印）疊在另一張相片上；純文字的標籤用 `<PhotoBack>`；記號是直條；不編號。
- **翻翻**：卡片是一張相片——照片嵌在白邊（`edge`）裡，右下日期壓印、▶ 影片 / N 張在照片上，欄目標、內文、資訊列印在白邊上（`onEdge` / `onEdgeMuted`，「精選」也用 `onEdge`，因為 `accent` 在深色模式的亮白邊上不夠清楚）。純文字卡整張是相片背面（整面橫線的紙，字用 `t.tag(hue).onPaper` / `.onPaperMuted`）。下方按鈕方角。
- **串流**：每篇前面一條齒孔條（不畫細線）；媒體是相片（左右各留 14，寬度 `width - 14*2 - PRINT_INSET`，日期壓印用 `savedAt`）；純文字貼文是大一號的相片背面；欄目標用 `<TagKicker>`。
