# 收藏牆（首頁）— 頁面規格

> 覆蓋 MASTER 的部分以本檔為準；沒寫到的照 MASTER。

## 版面（由上到下）

```
┌ 安全區 ───────────────────────────────┐
│ 收藏                         [搜尋][⚙] │  頂部列：display 字級；右側圖示按鈕 48dp
│ ┌ 搜尋作者或內文 ─────────────────┐   │  搜尋列：field 底色、高 44、圓角 md（點了才展開，平常收在頂部列的搜尋圖示也可）
│ 全部  追星  生活  美食  旅遊  +2      │  大標籤列：換行最多兩行，其餘收進 +N
│   └ 已選「追星」時： 某團A  某團B  …   │  小標籤列：縮排 8，同色系
├───────────────────────────────────────┤
│ ┌───────────────────────────────────┐ │  精選卡：整排
│ └───────────────────────────────────┘ │
│ ┌────────────┐ ┌────────────┐         │  兩欄瀑布流，欄距 8、左右邊距 16
│ │            │ │            │         │
│ └────────────┘ └────────────┘         │
│                               ( + )   │  FAB：右下，距安全區底 16、距右 16，直徑 56
└───────────────────────────────────────┘
```

- 欄寬＝(螢幕寬 − 16×2 − 8) ÷ 2。360 寬時每欄 156，412 寬時每欄 182。
- 平板 / 橫向（寬 ≥ 600）改三欄，邊距 24。
- 列表底部留 FAB 高度＋24 的空間，最後一張卡不被 FAB 蓋住。

## 瀑布流排列規則

1. 依收藏時間新到舊。
2. 一般卡片放進目前較矮的那一欄（依預估高度）。
3. 遇到精選卡：先結束目前兩欄，精選卡佔整排，之後兩欄重新從等高開始。
4. 預估高度：媒體高＝欄寬 × 高寬比（限制 0.75–1.6）；文字依字數估行數。

## 卡片尺寸

| 部位 | 規格 |
| --- | --- |
| 卡片 | card 底、1px border、圓角 md、內距 12（媒體貼齊上緣與左右，不留內距） |
| 媒體 | 依比例；骨架為 muted 底色 |
| 內文摘要 | `card` 字級，媒體卡最多 2 行、引言卡最多 8 行（serif `quote` 字級） |
| 作者列 | 頭像圓點 20（作者名第一個字＋大標籤色）＋ `@handle`（meta 字級，單行省略） |
| 標籤 | display 變體，最多 2 個＋「+N」 |
| 精選卡 | 媒體高寬比限制 0.5–0.75（橫向感）；三欄版面（寬 ≥ 600）改為 0.3–0.45，否則橫向時一張圖就佔滿整個畫面。摘要 3 行（`headline` 字級）、左上「★ 精選」角標 |

## 狀態

| 狀態 | 呈現 |
| --- | --- |
| 讀取中（剛收藏） | 骨架：媒體區 muted＋兩條灰線；作者列顯示「讀取中…」；有 1.2 秒一次的淡入淡出呼吸（減少動態時不動） |
| 讀取失敗 | 圖示 alert-circle＋「讀取失敗」＋「重試」文字按鈕（accent） |
| 原貼文已刪除 | 右上角標「已刪除」（scrim 底），其餘照常 |
| 已下載 | 右下角小圖示 download（scrim 底圓形 20） |

## 篩選與搜尋

- 篩選中時，標籤列下方顯示「12 篇 · 清除篩選」。
- 選小標籤會取代它的大標籤（縮小範圍），選大標籤會取代它底下已選的小標籤（放大範圍）；不同大類之間是聯集。
- 大標籤超過 5 個時，第 6 個起收進「+N」；已選的標籤永遠顯示，不會被收起來。
- 搜尋即時比對作者與內文（輸入停止 250ms 後更新，`debounce-throttle`）。
- 沒結果：空狀態（見 MASTER §9）。

## 互動

- 點卡片 → 推入貼文內容頁（共用元素：媒體從卡片位置放大，減少動態時改淡入）。
- 長按卡片 → 卡片選單面板（設為 / 取消精選、編輯標籤、下載、在 Threads 開啟、刪除），並輕觸覺回饋。
- 下拉重新整理：重新讀取「讀取中 / 讀取失敗」的卡片。
- 返回首頁保留捲動位置與篩選。
