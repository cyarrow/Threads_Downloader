# 第二、三階段 — 頁面規格

> 依據：MASTER、研究 agent 的競品報告（`docs/overnight-progress.md` 有摘要）、三個創新 agent 的雛形。
> 覆蓋 MASTER 的部分以本檔為準。

## 智慧標籤建議（收藏面板）
- 來源：同作者過去用過的標籤（權重最高）＋內文關鍵字（標籤名稱與內建字典）。小標籤會吸收它的大標籤，不同時建議「追星」和「追星 › 某團」。
- 位置：「建議」區在「最近用過」上方，最多 3 個；每個都寫出原因（「同作者有 2 篇用過 · 內文提到「巡演」」），讓人看得出為什麼、也看得出錯。
- **只建議、不自動勾選**：建議要等貼文讀完才出現，自動勾選等於在手指下方改變狀態。之後依採用率再評估。
- 已出現在建議的標籤不再重複出現在「最近用過」。

## 整理未分類（Triage）
- 入口：收藏牆標籤列下方「整理未分類（N 篇）」，只在有未分類、且沒在篩選時出現。
- 一次一篇：上方預覽，下方 3 個 56dp 大按鈕（建議標籤＋原因）、「其他標籤」、「略過」。沒有滑動手勢。
- 佇列在進入時固定，標好的不會讓畫面跳動；頂部有「N/總數」與進度條；結束顯示分類幾篇、略過幾篇。

## 標籤管理
- 設定 → 標籤管理。大標籤一張卡，小標籤縮排在下面，每列顯示篇數。
- 點一列打開編輯面板：改名（同層不可重名，最多 20 字）、換顏色（只有大標籤；小標籤一起換）、合併到…、刪除。
- **刪除要在面板內確認**，並寫出影響幾篇、「貼文本身不會被刪除」（MASTER：會影響多張卡片的刪除才確認）。
- 合併：貼文全部移到目標標籤，來源的小標籤一起搬過去。

## 回顧卡
- 牆頂端，只在沒有篩選、沒有搜尋時出現。
- 有「N 年前的今天」就顯示；否則「好久沒看」（收藏超過 30 天），每天固定同一組。
- 3 張縮圖，點了開內容頁；「隨機翻翻」換一批；✕ 收起（本次開啟期間）。

## 搜尋
- 也比對標籤名稱（搜「旅遊」會找到標了旅遊、但內文沒寫旅遊的貼文）。

## 第三階段：備份
- 設定 → 匯出備份：JSON（標籤＋貼文文字與連結，不含封面檔），用系統分享選單存到雲端硬碟或傳給自己。檔名 `threads-collection-YYYYMMDD.json`。
- 設定 → 匯入備份：選檔後合併——同名標籤沿用、已有的貼文略過、封面在背景重新抓。提示「匯入 N 篇，M 篇已經有了」。
- 格式是一般 JSON，就算沒有這個 App 也讀得懂（研究：Pocket、LINE Keep 關閉時使用者資料一起消失）。

## 延後（第四階段以後）
- 批次選取（三態標籤）、作者頁、標籤看板、「想去／去過了」、快速面板＋直接收藏模式、Android 分享選單直達標籤（Sharing Shortcuts）、透明分享頁。
- 視覺方向「雜誌」（visual agent 建議）：等使用者在實機上比較後決定。
