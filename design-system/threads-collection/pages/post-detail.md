# 貼文內容頁 — 頁面規格

> 覆蓋 MASTER 的部分以本檔為準；沒寫到的照 MASTER。

## 版面

```
┌ 安全區 ───────────────────────────────┐
│ [←]  @author                    [⋯]   │  頂部列：返回、作者、更多（在 Threads 開啟、刪除）
├───────────────────────────────────────┤
│ ┌───────────────────────────────────┐ │  媒體輪播：整寬，高寬比依第一張（限制 0.75–1.25）
│ │                                   │ │  多張時：右上「2/5」、下方指示點
│ └───────────────────────────────────┘ │
│ ● ○ ○ ○ ○                             │
│ 完整內文（body 字級，不截斷）            │
│ 收藏於 10月29日                          │  meta 字級，mutedForeground
│ 標籤                          編輯標籤 › │
│ [追星 › 某團A] [生活]                   │  display 標籤，換行
├───────────────────────────────────────┤
│ [   ⬇  下載到相簿   ]  （primary）     │  底部動作區：固定在底，避開手勢列
│ [☆ 設為精選] [↗ 在 Threads 開啟]       │  次要動作：tinted / 文字按鈕
└───────────────────────────────────────┘
```

## 規則

- 整頁只有一個主要按鈕：未下載時是「下載到相簿」；已下載時換成「再次下載」（次要樣式），主要按鈕位置不顯示墨色填色。
- 「刪除」放在更多選單，與其他動作分開（`destructive-nav-separation`），刪除後回到收藏牆並顯示「已刪除 · 復原」。
- 長按卡片能做的事，這頁都有按鈕：設為精選、編輯標籤、下載、在 Threads 開啟、刪除。
- 純文字貼文：沒有媒體區，內文改用 `quote` 字級（文楷）。
- 原貼文已刪除：媒體區顯示本機縮圖＋「原貼文已刪除，無法下載原檔」說明，下載按鈕停用。
- 媒體輪播是本頁唯一的水平滑動；有頁碼與指示點，指示點也可以點。
- 影片：顯示封面＋播放按鈕，點了才載入播放（不自動播放；減少動態時同樣不自動播放）。
