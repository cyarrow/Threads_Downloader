# 貼文內容頁 — 頁面規格

> 覆蓋 MASTER 的部分以本檔為準；沒寫到的照 MASTER。
> 雜誌方向（2026-11-02）：這頁讀起來像雜誌的一篇文章 — 照片、欄目標、文楷內文、署名、細線分隔，**沒有色塊盒子**。

## 版面

```
┌ 安全區 ───────────────────────────────┐
│ [←]  @AUTHOR                    [⋯]   │  頂部列（頁眉）：返回、作者（kicker 字級、mutedForeground）、更多
├───────────────────────────────────────┤  細線（border，hairline×2）
│ ┌───────────────────────────────────┐ │  媒體輪播：整寬，高寬比依第一張（限制 0.75–1.25）
│ │          （圖上不放任何東西）      │ │  影片：封面＋中央播放鈕（唯一疊在圖上的元素）
│ └───────────────────────────────────┘ │
│ ▬ ▪ ▪                          1 / 3  │  多張時：圖片下方一列 — 左邊頁碼記號、右邊「1 / 3」（caption）
│                                       │
│ ■ 美食 › 早午餐                        │  欄目標：標籤色小方塊＋「大標籤 › 小標籤」（kicker，標籤字色）
│                                       │  精選時前面多一個 accent「精選」；沒標籤＝slate 方塊＋「未分類」
│ 完整內文（content 字級＝文楷，不截斷）   │
│ ───────────────────────────────────── │  細線
│ 文 ／ @author                          │  署名：label 字級，「文 ／」用 mutedForeground
│ 收藏於 2026年11月2日                    │  日期：caption、字距 1、mutedForeground
│ ───────────────────────────────────── │  細線
│ 標籤                       編輯標籤 › │  區塊標題用 kicker（mutedForeground）；連結 accent，點擊高 48
│ [■ 美食 › 早午餐] [■ 生活]             │  display 標籤，換行
├───────────────────────────────────────┤  細線（border）
│ [   ⬇  下載到相簿   ]  （primary）     │  底部動作區：background 底（不是 card），固定在底，避開手勢列
│ [☆ 設為精選] [↗ 開啟原文]              │  次要：細框按鈕（border、圓角 sm），和標籤膠囊同一套
└───────────────────────────────────────┘
```

- 內文欄左右邊距 `20`，和收藏牆的畫面邊距對齊。
- 區塊之間只用細線（`border`，`hairlineWidth × 2`）分隔，不用底色盒子或卡片框。
- 頁碼記號：方角小方塊 8×8，目前那一張拉長成 20 寬＋墨色（**形狀也不同，不只靠顏色**），其餘 `border` 色；記號可以點，點擊範圍靠 padding＋hitSlop 補到約 40 高（沿用原本的數值）。

## 按鈕

| 按鈕 | 樣式 |
| --- | --- |
| 主要（`PrimaryButton`） | `primary` 墨色填滿、`onPrimary` 字、圓角 `sm`、高 52、`headline` 字級＋字距 1 |
| 次要（`SecondaryButton`） | 透明底、1px `border` 細框、圓角 `sm`、高 ≥ 48、`label` 字級；危險動作只把字和圖示換成 `danger` |

## 規則

- 整頁只有一個主要按鈕：未下載時是「下載到相簿」；已下載時換成「再次下載」（次要樣式），主要按鈕位置不顯示墨色填色。
- 「刪除」放在更多選單，與其他動作分開（`destructive-nav-separation`），刪除後回到收藏牆並顯示「已刪除 · 復原」。
- 長按卡片能做的事，這頁都有按鈕：設為精選、編輯標籤、下載、在 Threads 開啟、刪除。
- 純文字貼文：沒有媒體區；欄目標下面是和卡片一樣的「標籤色文字卡」（`tagTint` 當紙、左上標籤色大「「」），內文用 `quote` 字級（文楷）。
- 原貼文已刪除 / 舊紀錄補資料中：說明放在「編按」樣式的一列 — 上下各一條細線、圖示＋`meta` 字（mutedForeground），不用底色盒子。原貼文已刪除時下載按鈕不顯示。
- 媒體輪播是本頁唯一的水平滑動；有頁碼與指示記號，記號也可以點。頁碼放在圖片下方，不疊在照片上。
- 影片：顯示封面＋播放按鈕，點了才載入播放（不自動播放；減少動態時同樣不自動播放）。播放按鈕的 Pressable 要給明確的 `{ width, height }`，不可用 absoluteFill（Android 會縮成內容大小、▶ 跑到頂端）。
