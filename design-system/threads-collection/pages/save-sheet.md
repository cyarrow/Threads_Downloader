# 收藏面板 — 頁面規格

> 從 Threads 分享進來，或在 App 按 ＋ 貼上連結後出現。覆蓋 MASTER 的部分以本檔為準。
>
> 兩種樣子：**快速面板**（從 Threads 分享進來、設定「分享時用快速面板」開著時；見下方〈快速面板〉）和**完整面板**（＋ 貼上連結、編輯標籤、快速面板按「其他標籤…」之後）。

## 完整面板版面（固定高度＝面板上限 88%，內容在裡面捲動）

```
┌───────────────────────────────────────┐
│               ────                    │  拖曳把手（可下滑關閉）
│ 已收藏                          [✕]   │  title 字級；關閉圖示 48dp
│ ┌────┐ @author                        │  貼文預覽：縮圖 56、作者、內文 2 行
│ │    │ 內文第一行……                    │  讀取中時是骨架＋「讀取中…」
│ └────┘                                │
│ 加上標籤                               │  區塊標題（headline）
│ 最近用過： [追星 › 某團A] [生活]         │  最近 5 個，choice 變體
│ [追星 ▾] [生活] [美食] [旅遊] [梗圖]    │  大標籤；有小標籤的帶 ▾，點開下一列
│   └ [某團A ✓] [某團B] [+ 新增小標籤]    │
│ [+ 新增標籤]                            │
│                                       │
│ 同時下載到相簿                  (●  )  │  Switch，整列可點，記住上次選擇
│ [            完成             ]       │  primary，固定在面板底部、避開手勢列
└───────────────────────────────────────┘
```

## 行為

1. 面板一出現，貼文就**已經存好**（放在「未分類」），所以標題是「已收藏」而不是「要收藏嗎」。關閉面板＝保留收藏、不加標籤，不需要確認。
2. 讀取貼文內容（數秒）和選標籤同時進行，選標籤不必等讀取完成。
3. 可多選；可同時選大標籤本身和它的小標籤（例如只選「追星」＝之後再細分）。
   - **有小標籤的大標籤：點一下是展開 / 收合，不是選取**（雛形驗證後的決定：多數時候要選的是小標籤，「先選大再取消」太繞）。展開列第一個是「整個「追星」」，用來標大標籤本身。
   - 大標籤只有「它本身被選」時才顯示已選樣式；只選了底下的小標籤時，大標籤顯示「追星 · 1」這種數量，不填色，避免誤會大標籤也被標了。
   - 沒有小標籤的大標籤：點一下直接選取 / 取消。
4. 「+ 新增標籤」：原地變成輸入框（visible label「新標籤名稱」），下方可選「放在哪個大標籤底下」（預設：無＝新的大標籤）與顏色（新大標籤自動選下一個未使用的顏色，可改）。名稱重複時欄位下方顯示錯誤。
5. 「完成」：套用標籤 → 面板關閉 → 觸覺回饋＋提示「已收藏到 追星 › 某團A」。從 Threads 分享進來時，接著自動回到 Threads。（快速面板的標籤列、「先存到未分類」走同一條路。）
6. 開了「同時下載」：完成後進下載排隊，提示改為「已收藏，下載中」。

## 快速面板（分享進來時）

```
┌───────────────────────────────────────┐
│ 已收藏                          [✕]   │
│ ┌────┐ @author                        │  貼文預覽（同完整面板）
│ └────┘ 內文……                          │
│ 加上標籤                  點一下就完成  │  headline ＋ meta
│ ┌───────────────────────────────────┐ │  一個細框清單（border、圓角 4），列與列之間細線
│ │ ■ 追星 › 星光少年團                 │ │  ■＝標籤色小方塊 12×12；名稱 headline（小標籤顯示「大 › 小」）
│ │   同作者常用                        │ │  理由 meta、mutedForeground；沒有理由就只有名稱
│ ├───────────────────────────────────┤ │  每列 64（≥ 56dp），整列可點
│ │ ■ 美食                             │ │
│ │   內文提到「拉麵」                   │ │
│ ├───────────────────────────────────┤ │
│ │ ■ 生活                             │ │
│ │   最近用過                          │ │
│ ├───────────────────────────────────┤ │
│ │ ◇ 其他標籤…                     ⌄  │ │  ◇＝pricetags 圖示  展開成完整面板（之後不會再縮回）
│ └───────────────────────────────────┘ │
│ 同時下載到相簿                  (●  )  │  和完整面板同一個開關、同一個行為
│ [          先存到未分類          ]     │  細框（foreground 1px）按鈕，位置＝完整面板的「完成」
└───────────────────────────────────────┘
```

**行為**
1. 點任一標籤列＝只用這個標籤收藏並結束，流程和按「完成」完全一樣：觸覺回饋、系統提示「已收藏到 X」、開了同時下載就進下載排隊（下載完才回 Threads），否則自動回到 Threads。點下後整列填墨色、小方塊換成 ✓，其他列停用，第二下不會重複儲存。
2. 「先存到未分類」＝不加標籤的「完成」（同樣會下載／回 Threads）。關閉（✕、下滑、返回鍵）和以前一樣：留在未分類、回 Threads、不下載。
3. 「其他標籤…」：面板換成完整面板（可多選、新增標籤、「完成」）。
4. 已經收藏過的連結（直接認得出的）照舊開「編輯標籤」，不用快速面板。分享連結讀完才發現是舊卡片時，選的標籤會**加到**舊卡片原本的標籤上，不會蓋掉。

**哪三個標籤**（`src/collection/quickSave.js` 的 `rankQuickTags`，有單元測試）
1. 建議（`suggest.js`：同作者用過的標籤、內文提到的字），依建議分數；
2. 最近用過（store 的 `recent`，新的在前）；
3. 都不夠時補大標籤（依標籤順序），第一次用的人也有按鈕可點。
- 不重複；已經列出某個小標籤時，不再列它的大標籤（具體的優先）。
- 理由文字：同作者 1 篇「同作者用過」、2 篇以上「同作者常用」；「內文提到「X」」；「最近用過」；補上的大標籤不寫理由。

**讀取中也能用，按鈕不會在手指下換位置**
- 面板一打開，貼文通常還在讀（作者、內文要幾秒才到，建議要靠它們）。標籤列先顯示和真正按鈕一樣高的骨架列（最多 3 列，`slotCount`），無障礙名稱「正在找適合的標籤」。「其他標籤…」、「先存到未分類」、下載開關、關閉從一開始就能按，而且位置不會變。
- 貼文讀完，或等了 **1.5 秒**（`SETTLE_MS`）還沒讀完，就用當下最好的結果畫出按鈕，**畫出來之後就鎖定**（`lockPicks`）：之後才到的建議不會插隊、不會換掉或重排任何一列。晚到的建議改在「其他標籤…」裡的完整面板出現。
- 取捨：等太久會拖慢「一點就走」；不等又幾乎用不到「同作者」這個最準的訊號。1.5 秒內讀完（常見於網路好時）就用得到；讀不完就先給最近用過的。
- 快速面板的高度跟著內容，面板底部固定在螢幕下緣，所以骨架換成較少列時，只有上方的預覽往下移，下方的按鈕不動。

**設定**：設定頁「分享時用快速面板」開關（預設開，存在 meta `quick_save`，和 `download_too` 一樣記在手機上）。關掉後分享進來直接開完整面板。在 App 內按 ＋ 收藏一律是完整面板。

## 不讓點的東西移位（兩種面板都適用）

- **展開大標籤不跳**：以前面板高度跟著內容、又固定在螢幕底部，點開大標籤時下面多一列小標籤，整個面板往上長，剛點的那顆連同上面所有東西一起往上跳（實測 136px；接近最高時 28px）。現在完整面板一打開就是固定高度（面板上限 88%），內容在裡面捲動，小標籤列只會往下長，手指下的那顆不動（實測位移 0）。
- **建議晚到不推擠**：完整面板打開時已經有的建議固定在最上面；打開之後才讀到的建議放在全部標籤**後面**，不插到使用者正要點的標籤上方（`lateSuggestions`）。「最近用過」只排除已經在上方的建議，所以不會因為建議到了而少一顆、整排往左縮。
- 貼文預覽一開始就留好「作者＋兩行內文」的高度，讀完不會長高。

## 細節

- 標籤列換行顯示，不水平捲動；大標籤超過兩行時收進「+N」可展開。
- 已選標籤：tag 已選色＋✓ 圖示；`accessibilityRole="checkbox"`。
- 面板開啟時背後加 `scrim`；鍵盤出現時面板往上推，輸入框不被遮住。
- 開關關閉時的軌道色用 `mutedForeground`（`border` 色和面板只有約 1.3:1，看不出開關在哪），開啟用 `primary`，圓鈕白色。
- 新增的大標籤自動配下一個還沒用過的顏色（slate 保留給未分類）；新增的小標籤沿用大標籤顏色。
- 減少動態效果時：面板淡入，不滑入。
